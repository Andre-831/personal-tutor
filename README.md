# Personal Tutor

AI-powered desktop tutor for chatting with class materials and generating personalized study tools.

## Features

- AI tutor chat
- Upload and analyze class materials
- Class-specific AI context
- PDF ingestion
- AI-generated flashcards
- Persistent conversations
- Local SQLite storage

## Tech Stack

- Electron
- React
- TypeScript
- Vite
- SQLite
- Gemini
